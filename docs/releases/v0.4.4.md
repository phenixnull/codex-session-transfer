# Codex Session Transfer v0.4.4

## Improvements

- Source and Target provider controls now use one provider catalog and show configured display names together with real provider IDs, including `xixiapi (id: custom)`.
- Copy and package import no longer require Preview first; both show live progress through completion.
- Large preview plans load 48 items initially and fetch additional pages only while the user scrolls.
- Session list payloads are compacted for large databases while detailed rollout rendering remains available on demand.
- Provider switching clears selection and preview state immediately, and blocking or invalid-provider errors are shown before any write.

## Verification

- 64 Python unit, transaction, and HTTP-stream tests
- Frontend, responsive-layout, Electron, window-constraint, workspace-mapping, and release-workflow checks
- Real 2,207-session provider list, paged preview, same-provider, descendant, blocked-copy, and package-import smoke tests
