# Codex Session Transfer v0.4.3

## Improvements

- Source and Target provider selectors now use the same provider ID for sessions stored in the local database.
- Target keeps the configured destination available as `live`; its configured display name appears only as a parenthetical hint, for example `custom (xixiapi) / live`.
- Target session counts are labeled as totals so archived sessions do not appear as an unexplained mismatch.
- Codex++ preset and override providers no longer appear as separate Target choices. Use `Custom provider id...` when a destination is not present in the local database or current configuration.

## Verification

- 52 Python unit and transaction tests
- Frontend, responsive-layout, Electron IPC, and release-workflow checks
- Windows package build with SHA-256 manifest generation
