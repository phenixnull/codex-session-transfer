# Codex Session Transfer v0.4.5

## Fixes

- Added `Rebind provider` for local sessions. It updates the SQLite provider and rollout `session_meta` provider in one transaction while preserving the original session ID, title, archive state, transcript, and `session_index.jsonl` entry.
- Rebinding is blocked while Codex or the provider switcher is running, and it keeps a database backup plus rollout backups with the result manifest.
- Added direct rebind execution with live progress; it does not require rendering a preview of every selected session.
- Added rollback coverage for partial rollout-write failures.

## Verification

- 66 Python unit, transaction, HTTP-stream, and rollback tests
- JavaScript workspace, UI contract, window constraint, and release workflow checks
- Real local UI snapshot verified the rebind control and process-blocked state without modifying user sessions
