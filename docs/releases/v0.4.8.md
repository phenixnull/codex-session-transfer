# Codex Session Transfer v0.4.8

## Fixes

- Full provider Mirror now recognizes Windows extended paths such as `\\?\C:\Users\...\.codex\sessions\...` as the same location as their normal drive-letter paths.
- Safety checks remain path-segment aware and continue rejecting lookalike directories, other drives, device paths, and rollout files outside Codex session roots.
- Extended UNC paths are normalized consistently, while file operations retain their original extended path for long-path support.
- Backup-relative paths and rollout deduplication now use the same canonical Windows path rules.

- JavaScript workspace, UI contract, responsive Electron, runtime isolation, installer upgrade, window constraint, and release workflow checks
