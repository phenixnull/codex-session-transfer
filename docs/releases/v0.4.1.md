# Codex Session Transfer v0.4.1

## Fixes

- Same-provider session copies are now allowed in local mode.
- Package imports can target the same provider as the package source.
- An explicit `Overwrite matching sessions` option replaces destination sessions with matching package session IDs after preview.
- Overwrite imports replace related SQLite edges, dynamic tools, rollout files, and session-index entries as one recoverable operation.

- 46 Python unit and transaction tests
- Frontend mapping, overwrite-control, IPC, responsive-layout, window-constraint, and release-workflow checks
