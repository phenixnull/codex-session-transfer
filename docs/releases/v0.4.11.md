# Codex Session Transfer v0.4.11

## Fixes

- Provider session transfer is now vendor-agnostic: packages can move sessions from any source provider to any selected target provider.
- Exported packages include a sanitized provider catalog, including provider definitions discovered in local switcher presets.
- Import adds a missing target provider definition atomically, preserves an existing target definition, and rolls back `config.toml` if the import fails.
- Provider credentials and authentication state remain local: `auth.json`, API keys, `authText`, and authentication headers are never included in a package.
- The package UI lists provider definitions carried by the package and clearly marks providers that will be synchronized at import time.

## Verification

- 93 Python unit, transaction, HTTP-stream, concurrency, package, cross-provider, credential-redaction, and rollback tests
- JavaScript workspace, UI contract, responsive Electron, runtime isolation, installer upgrade, window constraint, and release workflow checks
- Read-only live preflight accepted the `Fucheers -> custom` full-provider plan with 2,620 sessions and no errors
