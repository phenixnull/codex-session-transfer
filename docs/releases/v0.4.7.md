# Codex Session Transfer v0.4.7

## Fixes

- Desktop builds now launch a dedicated local backend on a dynamically allocated loopback port instead of reusing any service found on fixed port `8765`.
- Each Electron instance and backend perform a 256-bit token handshake through `/api/health`, so an old or unrelated backend can never supply the UI.
- The Windows installer closes both the desktop process and any orphaned packaged backend before replacing application files, including copies running from an older install path.
- Packaged backends monitor their Electron parent PID and exit automatically after a normal close or host-process failure.
